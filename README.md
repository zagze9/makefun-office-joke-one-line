The whole entry is one line of at most 200 characters, written by a tiny
program to /output/entry.txt: a joke about office life, the sort of line you
send a colleague after a meeting that should have been an email.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

It writes the entry line, with no trailing newline, to the output directory.
